How implied value is computed

One function scores every protocol. No name is special-cased and no row is hand-picked.

implied = round( tvl_usd × category multiple × growth multiplier × maturity multiplier × breadth multiplier )

The four multipliers

  • Category multiple. The median market-cap-to-TVL ratio of the live-token protocols in the same category — the market's own yardstick, read from this snapshot. Categories with fewer than three live protocols use the global median.
  • Growth. Seven-day TVL change, clamped to −80%…+200%, weighted 0.6: 1 + clamp(change_7d) / 100 × 0.6.
  • Maturity. Saturating with age: 0.55 + 0.45 × (1 − e^(−age / 540)). Age is the time since the protocol was first listed; an unknown listing date uses the median pre-token age.
  • Breadth. 1 + 0.03 × min(chains − 1, 5): a protocol live on more chains has a wider distribution surface.

A note on words: the board says a protocol records no token, never that it has none — DefiLlama's record is not proof, and a protocol on the list may still have a token its record does not carry. Wrapped, staked and bridged products of tokens that already trade are left out of the ranking, as are exchanges and versioned pools. For the judge: the model is calibrated from the snapshot's own live-token multiples, the board covers every rankable pre-token protocol in the snapshot, and every farm plan is generated per protocol from its category, chains, TVL and age, with a cost and a time on each step.
